Autoencoder Detection Theory

How the unsupervised deep learning neural network identifies banking transaction anomalies

Unsupervised Reconstruction Telemetry

This system uses an unsupervised autoencoder neural network trained exclusively on historical healthy transaction data. The model learns to compress ledger coordinates into a low-dimensional latent space bottleneck and reconstruct them. Transactions that deviate significantly from these learned normal patterns produce high reconstruction errors and are automatically flagged based on their Mean Squared Error (MSE).

Model Architecture Autoencoder Unsupervised deep learning
Error Metric MSE Mean Squared Error
Scoring Threshold 0.0450 Max of p99 and mean + 3σ
Ingestion System Async Queue Scoring thread + worker
1

Train on normal transactions

The neural network trains exclusively on historical transactions considered normal. It learns optimal weights to compress and reconstruct core features: amount, type, channel, and 30-day user rolling envelopes.

2

Score each new transaction

When a new ledger ingest arrives, the encoder compresses features into a latent bottleneck, and the decoder reconstructs them. Normal transactions reconstruct with low error; anomalous ones do not.

3

Flag if error exceeds threshold

If the calculated Mean Squared Error (MSE) exceeds the dynamic limit, an alert is triggered immediately. Transactions are written to the alerts feed with a critical threat index.
